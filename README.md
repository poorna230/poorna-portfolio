# Poorna Chandra Rao — Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. No framework, build step, or paid service is required.

## Before publishing

1. Open `index.html`.
2. Your professional portrait is included at `assets/profile-photo.jpg` and is displayed in the hero section.
3. Your GitHub, LinkedIn, and LeetCode profile links are already personalized.
4. Project cards currently link to your GitHub profile because exact repository URLs were not provided; replace them with individual repository URLs when available.
5. Check the resume details, phone number, email, dates, and CGPA for accuracy.

## Free hosting: GitHub Pages

1. Create a GitHub repository named `poorna-portfolio` (or `YOURUSERNAME.github.io`).
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site will be available at `https://YOURUSERNAME.github.io/poorna-portfolio/` (or `https://YOURUSERNAME.github.io/` if you used the special repository name).

You can also deploy the folder for free using Netlify Drop: https://app.netlify.com/drop
